# Invoice Reader

离线 Windows PDF 发票处理工具。

当前版本为阶段 3，提供：

- 打开单张 PDF；
- 鼠标滚轮连续浏览、缩放和滚动条移动；
- 鼠标拖拽多个框选并显示序号；
- 右侧按序号实时显示每个框选区域中的 PDF 文字层文本；
- 点击框选后按 Delete 删除。
- 可配置并保存 PLMN 文件名片段模式；
- 在窗口内测试文件名或真实 PDF 的 PLMN 解析。
- 四个具名字段的跨页标准化框选；
- 本地 YAML 模板的保存、加载和自动匹配。

## 运行源码

```powershell
python -m pip install -r requirements.txt
python -m invoice_reader
```

## 运行单元测试

```powershell
python -m pip install -e ".[test]"
pytest
```

## 阶段 3 EXE 验证

打开 `InvoiceReaderPhase1.exe` 后：

1. 点击“打开 PDF”。
2. 滚动鼠标滚轮连续浏览页面；在当前页底部继续向下滚会进入下一页，顶部继续向上滚会回上一页。
3. 使用“放大 / 缩小 / 100%”调整预览；放大后滚轮会先连续移动当前页面内容。
4. 在页面上按住鼠标左键拖拽多个文字区域，确认每个框显示序号。
5. 查看右侧“框选文字”区域是否按序号显示每个框的文字。
6. 点击一个框后按 Delete，确认该框和对应右侧文字都被删除并重新编号。
7. 在顶部“PLMN 文件名测试”中输入一条或多条模式（每行一条，例如 `<PLMN>_MACHT`），输入文件名或选择真实 PDF，点击“解析并保存模式”。
8. 确认显示提取出的 PLMN；没有命中时显示“需手动填写”。重启程序后确认模式仍保留。
9. 在“模板”区域选择要框选的字段，分别在 PDF 上框选 Invoice No.、SDR amount、TAP start 和 TAP end；可跨页框选。
10. 关键词备注可选填写；点击“保存新模板”后，程序自动从当前 PDF 文件名解析 PLMN，并把它同时作为模板名、公司名和 YAML 的 `plmn` 字段。解析失败时按提示手动输入 PLMN。模板只保存到本机 `%LOCALAPPDATA%\InvoiceReader\templates\`。
11. 重启程序并打开同一 PLMN 的 PDF，确认自动出现四个字段框；翻页再返回，确认原页字段框仍存在。
12. 应用已有模板后可修改模板名、公司名、关键词或重新框选字段，再点击“保存修改”；它会覆盖原本机 YAML。
13. 应用已有模板后点击“删除模板”，确认删除后该模板不再出现在本机模板列表中。

阶段 1 仅支持有文字层的 PDF；OCR、模板、Excel 和归档会在后续阶段加入。
